# SOLIDWORKS 工程图宏使用说明

## 宏功能概述

本宏专为普通截面旋转拉伸类零件（如 O 形圈、挡圈、导向环、密封环等）及其装配体设计。运行后，宏将自动完成：

1. 加载同目录下的工程图尺寸规范。
2. 检索并关联同名 3D 模型。
3. 自动生成前视、俯视以及剖视图。
4. 智能计算比例、生成断裂视图并清理图纸。
5. 导入模型尺寸、调整公差字体，并智能处理粗糙度符号。

## 准备工作

1. 保存图纸：当前工程图已保存在本地
2. 命名规范：图纸名称（Sheet Name）建议与需导入的模型名称高度相似（宏会根据字段匹配同目录的模型）；如 O 形圈、挡圈等，建议直接使用标准学名命名模型和图纸，便于宏精准识别其特殊目标高度和几何特征。
3. 确保宏文件所在文件夹内包含 工程图尺寸规范.sldstd 文件。
4. 请尽量保证导入前图纸内部整洁，不要有过多的草图元素。

## 使用步骤

1. **准备图纸**：打开并保存工程图，切换到目标图纸，确认图纸名与同目录下的模型对应。
2. **运行宏**：点击菜单栏“工具 > 宏 > 运行”，选中并运行该宏脚本。
3. **确认模型**：在弹出的提示框中确认自动匹配的模型，或手动选择正确的模型文件。
4. **检查保存**：等待宏运行完毕，人工核对剖视图位置、比例、断裂及尺寸标注等，确认无误后保存图纸。

## 将运行宏添加到快捷方式栏

1. 在“选项下拉框 > 自定义”，选择“快捷方式栏”选项卡。
2. 在搜索框中输入“宏”，在“按钮栏”找到对应命令图标。
3. 将“运行宏”图标拖到快捷方式栏中，点击“确定”。之后可在菜单栏中通过该图标选择并运行宏。

## 主要参数

在 VBA 编辑器内可搜索变量名修改。

|参数变量 / 代码位置|默认值|作用说明|
|:--|:--|:--|
|`stdName`|`"常用"`|加载的 `.sldstd` 文件内部标准名称。|
|`sectionPosX`|`0.1555` (m)|剖视图基准横坐标（图纸高度一半为纵坐标）。|
|`sectionDir` / `sectionDepth`|`"BN"` / `0.128` (m)|剖切方向与深度，实际生成时纵向再加 0.01m。|
|`ASSEMBLY_TARGET_HEIGHT_MM`|`37` (mm)|装配体目标高度（通过轮廓两次测量求比例）。|
|`targetHeight`|`25` / `35` (mm)|零件目标高度：密封类 25，其他 35（比例按0.1取整，最低0.1）。|
|`borderMargin_mm` / 阈值|`10` / `40` (mm)|图框边距；距图框左右小于 40mm 触发断裂。|
|`targetCenterDist`<br/>`targetInnerDist`|导向环:`40/30`<br/>其他:`30/25` (mm)|断裂线中心距与内径距。|
|`LARGE_SECTION_WIDTH_MM`|`35` (mm)|截面宽度大于此值按大截面处理。|
|`myView.BreakLineGap`|`0.003` (m)|断裂线间隙（3 mm）。|
|`stepX10` / `stepY10`|粗:`0.01/0.005`<br/>细:`0.005/0.001`|扫描隐藏断裂草图的步长。|
|`swDimTol125.SetFont`|类型 2:`0.8`<br/>类型 4:`1.0`|带公差尺寸的字体缩放比例。|
|`sfValue` / `sfText`|`3.2` / `全部`|自动插入的粗糙度数值和文字。|
|`sfMarginX` / `sfMarginY`|`0.025` / `0.03` (m)|粗糙度距图纸右、上边缘的距离。|
